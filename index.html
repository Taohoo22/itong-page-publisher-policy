2. ข้อมูลที่ใช้

แอปอาจรับและเก็บข้อมูลต่อไปนี้เท่าที่จำเป็นต่อการทำงานที่ได้รับอนุญาต:

  • ข้อมูลระบุตัวผู้อนุญาตเชื่อมต่อ เช่น รหัสผู้ใช้ ชื่อ และข้อมูลโปรไฟล์สาธารณะที่ Meta ส่งให้ตามสิทธิ์
  • รหัสและชื่อเพจ รายการเพจที่เลือกเชื่อมต่อ บทบาทหรือหน้าที่ของผู้ดูแล และสถานะสิทธิ์เข้าถึง
  • โทเค็นเข้าถึง API และข้อมูลอายุหรือสถานะของโทเค็น เพื่อเชื่อมต่อเพจโดยได้รับอนุญาต
  • ข้อความ ภาพ วิดีโอ และข้อมูลประกอบของโพสต์ เช่น รหัสโพสต์ ลิงก์ เวลาเผยแพร่ และสถานะประมวลผล
  • บันทึกการอนุมัติและผลการทำงาน เช่น ข้อผิดพลาดจาก API และหลักฐานตรวจสอบว่าโพสต์ถูกเพจและไม่ซ้ำ
  • ข้อมูลติดต่อและรายละเอียดที่เจ้าของข้อมูลส่งมาเมื่อขอความช่วยเหลือหรือขอใช้สิทธิ

สิทธิ์ที่ใช้ในปัจจุบันคือ public_profile, pages_show_list, pages_read_engagement และ pages_manage_posts การมีสิทธิ์ไม่ได้หมายความว่าแอปเก็บข้อมูลทุกช่องที่สิทธิ์นั้นเปิดให้เข้าถึง

แอปไม่ขอให้ส่งรหัสผ่าน Facebook หรือรหัสยืนยันตัวตนมาทางแชทหรืออีเมล การเข้าสู่ระบบและยืนยันตัวตนทำบนหน้าของ Meta โดยตรง ปัจจุบันแอปไม่ได้เปิดระบบอ่านข้อความส่วนตัวหรือจัดเก็บข้อมูลการชำระเงินของลูกค้า

3. วัตถุประสงค์

ใช้ข้อมูลเพื่อเชื่อมต่อเพจที่ได้รับอนุญาต ตรวจสอบตัวตนและสิทธิ์ของผู้ดูแล เผยแพร่เนื้อหาตามคำสั่ง ตรวจสอบผลการเผยแพร่ ป้องกันโพสต์ผิดเพจหรือซ้ำ แก้ไขข้อขัดข้อง และตอบคำขอเกี่ยวกับข้อมูลส่วนบุคคล

การเพิ่มงานใหม่ที่ต้องใช้ข้อมูลหรือสิทธิ์เพิ่มเติม เช่น อ่านข้อความส่วนตัวหรือจัดการโฆษณา ต้องผ่านการอนุญาตที่เกี่ยวข้องและปรับปรุงข้อมูลนโยบายก่อนใช้งาน ไม่ถือว่าการเชื่อมต่อเพจเป็นการอนุมัติงานทุกประเภท

4. การเปิดเผยและผู้ให้บริการ

เนื้อหาที่สั่งเผยแพร่จะถูกส่งให้ Meta และอาจแสดงต่อสาธารณะตามสถานะของโพสต์และข้อกำหนดของแพลตฟอร์ม ผู้ดูแลจึงควรตรวจสอบข้อมูลในเนื้อหาก่อนอนุมัติเผยแพร่

ผู้ดูแลที่ได้รับมอบหมายและผู้ให้บริการทางเทคนิคที่ใช้ดำเนินงานอาจประมวลผลข้อมูลเท่าที่จำเป็น เช่น บริการแพลตฟอร์ม ระบบสื่อสาร และเครื่องมือผู้ช่วย AI สำหรับงานเนื้อหาหรือวิเคราะห์ผลการทำงาน ต้องจำกัดข้อมูลที่ส่งให้เหมาะกับงานและปกปิดข้อมูลลับ

เราไม่ขายข้อมูลส่วนบุคคลที่ได้รับผ่านแอป อาจเปิดเผยข้อมูลเมื่อกฎหมายกำหนดหรือเมื่อจำเป็นต่อการรักษาความปลอดภัยและการใช้สิทธิตามกฎหมาย ผู้ให้บริการบางรายอาจประมวลผลข้อมูลนอกประเทศไทยภายใต้นโยบายและเงื่อนไขของตน

5. การเก็บรักษาและความปลอดภัย

จำกัดการเข้าถึงข้อมูลให้ผู้ดูแลที่จำเป็นต่อการทำงาน โทเค็น API ถูกเก็บในระบบจัดเก็บข้อมูลลับของอุปกรณ์ ไม่เผยแพร่ในหน้าเว็บ เอกสารสาธารณะ หรือที่เก็บซอร์สโค้ดสาธารณะ

เก็บข้อมูลเพียงเท่าที่จำเป็นต่อวัตถุประสงค์ข้างต้น การตรวจสอบความผิดพลาด และภาระหน้าที่ตามกฎหมาย เมื่อเลิกใช้การเชื่อมต่อหรือข้อมูลไม่จำเป็นแล้ว จะตรวจสอบและลบหรือทำให้ไม่สามารถระบุตัวบุคคลได้ตามประเภทข้อมูล

ไฟล์วิดีโอทำงานในเครื่องและบันทึกผลการเผยแพร่มีอายุเก็บต่างกัน การลบไฟล์ในเครื่องไม่ได้ลบโพสต์บน Facebook โดยอัตโนมัติ ส่วนข้อมูลสำรองหรือสำเนาที่อยู่กับผู้ให้บริการอาจมีข้อจำกัดและรอบการลบตามระบบของผู้ให้บริการนั้น

6. การถอนการเชื่อมต่อและการขอลบข้อมูล

ผู้อนุญาตเชื่อมต่อสามารถจัดการหรือถอนสิทธิ์แอปผ่านการตั้งค่าการผสานรวมธุรกิจของ Facebook การถอนสิทธิ์จะกระทบการเข้าถึงครั้งถัดไป แต่ไม่ได้ลบข้อมูลที่เคยเก็บหรือโพสต์ที่เผยแพร่แล้วทั้งหมดโดยอัตโนมัติ

หากต้องการขอเข้าถึง แก้ไข ลบ จำกัดการใช้ หรือใช้สิทธิอื่นตามกฎหมายที่เกี่ยวข้อง ให้ส่งอีเมลไปที่ Itongworkroom@gmail.com โดยระบุหัวข้อ คำขอข้อมูล — ITong Page01 Publisher พร้อมชื่อหรือลิงก์เพจ ข้อมูลที่ต้องการให้ดำเนินการ และช่องทางติดต่อกลับ

อย่าส่งรหัสผ่าน โทเค็น หรือรหัสยืนยันตัวตน เราอาจขอหลักฐานเท่าที่จำเป็นเพื่อยืนยันว่าผู้ร้องมีสิทธิในข้อมูลนั้น เมื่อยืนยันแล้วจะตรวจสอบและแจ้งผล รวมถึงอธิบายข้อมูลที่ไม่สามารถลบได้หากมีเหตุจำเป็นตามกฎหมายหรือข้อจำกัดของแพลตฟอร์ม

การขอลบข้อมูลที่แอปเก็บกับการขอลบโพสต์บน Facebook เป็นคนละเรื่อง โปรดระบุให้ชัดเจนหากต้องการให้ดำเนินการกับโพสต์ด้วย
